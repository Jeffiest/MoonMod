# Ascension and Dungeon+ legacy suite integration

> 2026-10-19: the Ascension package audited here became `moonmod.adventurer` and was then replaced by `moonmod.rpg` (RPG: Character Paths, see `mods/README.md`). Dungeon+ is current. The rest of this page is the audit as it was written.

This source audit covers the Chronicle packages in MoonFactory. The changes have not been run in the game or a headless test, following the user's instruction. The feature list describes the implementation and available API hooks; gameplay behavior still needs an in-game check.

For the broader Windows branch reconciliation (including autosave, controls, town/menu packages, the 3D replacement system, and the new room-based spawn scaling), see [LEGACY_MOD_PARITY_PLAN.md](LEGACY_MOD_PARITY_PLAN.md).

## Use the current MoonFactory manager

Open **Options > Game+ > Mod Manager**, select a package, and use its existing tabs. Ascension and Dungeon+ use Skills, Actions, Quests, Journal, and Settings; Controls exposes configurable keyboard bindings in Settings.

Open the in-game pause ring and choose **MODS** (the former Manuals slot) to open the existing Mod Manager. Press **Triangle** there to open the original game manuals. For quick navigation, select **MoonMod Hub** in Local Packages, open its **Actions** tab, and activate a destination; Chronicle switches to that loaded package and tab within the same manager.

- **Skills**: Ascension's three trees, ranks, prerequisites, and descriptions. Confirm trains the selected skill.
- **Actions**: progression status, casts, respec, weapon mastery, floor tiers, bounty and bestiary status, mutators, and Dungeon+ rewards.
- **Quests / Journal**: Dungeon Feats trophies and their progress and rewards.
- **Settings**: per-level dungeon bonuses, Ascension enemy/champion scaling, Sturdy refunds, weapon mastery, and Dungeon+ chance, reward, and speed settings.

The packages do not draw a separate HUD or custom menu. Their settings and actions use the manager's existing screens and its action notifications; the in-dungeon map uses Chronicle's native renderer, with **Dungeon Aerial Map** and **Fit Dungeon Map to Screen** display options in Game Options. Expanded Town's overhead camera is available from its Settings and Actions tabs and toggles with O or L1+L3 while walking in town.

## Legacy package mapping

- Character progression and combat features from `ascension`, plus weapon kill tracking from `weapon_mastery`, are in **Ascension**.
- Sturdy's durability and thirst refunds are integrated into Ascension Settings; Survivalist adds thirst refund per rank. Aga's Sword's flat incoming-damage guard is also retained.
- Dungeon tier/layout work from `dungeon_plus`, trophies from `dungeon_feats`, floor bounties from `floor_bounty`, mutators from `floor_mutators`, enemy variation from `enemy_variety`, and the five legacy revive-script overrides from `harder_ai` are in **Dungeon+**.
- The 64 base weapon definition edits, 119 prices, shop-list edits, and five-day daily stock rotations from `expanded_data` are in Dungeon+. Chronicle restores native definition, price, and shop-list edits when Dungeon+ unloads. The former standalone `hub` and `mod_settings` screens are replaced by MoonFactory's Mod Manager.
- **MoonMod Hub** adds quick links in its Actions tab to Ascension's Skills/Actions, Dungeon+'s Actions/Journal, Controls Settings, Autosave Settings, and Expanded Town Settings/Actions. Links use Chronicle's `game.ui.navigate` operation to move within the current Mod Manager, so the destination package must be enabled and loaded.
- **Autosave** provides an **Enable native town autosave** setting. It toggles Chronicle's separate autosave slot writer; the writer waits six seconds after a town loads, saves every four minutes, and only writes during safe exterior-town play.
- **Controls** adds configurable dungeon shortcuts for using the three native quick-item slots, switching to joined party members, and toggling first-person view. Quick items run through Chronicle's normal action-button path. Its mouse wheel routes to Left/Right during dungeon play and Up/Down for menus or non-dungeon contexts, through an owner-scoped Chronicle API that restores native zoom routing when the package unloads. In towns, keys 4–9 select joined party avatars and Select/Backspace cycles through those available; Chronicle loads the matching town model and remaps its animation motions without changing the dungeon party member.
- **Gameplay presets** are available as the first three Actions on Dungeon+: Relaxed, Normal, and Hardcore update the matching Ascension and Dungeon+ settings together. Normal restores those settings to each package's declared default. Changes take effect immediately for loaded packages and persist in the MoonFactory profile.
- `expanded_abilities` ports the eight effects in the shipped Windows script, including Mobius Ring's timed damage ramp, through native hit/status hooks. The source script excludes effects needing new visuals, clones, or weapon-generation rolls.

## Ascension

The manager exposes legacy defaults for the maximum level before Paragon, skill points, Focus regeneration, Shockwave radius, HP and damage gained per level, Paragon gains, level-based mitigation, XP and Gilda rewards, incoming dungeon damage, critical-hit chance and damage, damage variance, and champion threat radius and pressure. Learned active skills can be cast during dungeon play with configurable keyboard shortcuts (F4 Shockwave, F5 Second Wind, F6 Berserk by default) or from Ascension's Actions tab. Skill and status visuals stay in the Mod Manager.

Ascension contains 18 skill nodes across Might, Vitality, and Focus. It awards base XP on accepted enemy defeats using the legacy 45% of max HP plus native EXP formula, grants character levels and Paragon ranks, adds native maximum HP on progression, and applies supported combat bonuses through the skill and combat APIs. Each character has a separate skill tree and point budget; the manager Skills page shows the active character's ranks. Rank profiles, XP, Paragon, weapon mastery, and Toughness HP baselines are keyed by Chronicle's numbered slot plus its persistent generation. The generation changes when an in-game-deleted slot number is reused. Legacy shared ranks migrate to the character active on migration; in-game slot/character switching and deletion/reuse still need confirmation. Focus regenerates at the legacy 6 points per second plus Quick Recovery; Shockwave reaches enemies within 20 world units. Respec charges the configured Gilda amount per character level (100 default). Siphon heals the attacker for 2% of each hit's final damage per rank. Revealed active enemies scale by dungeon and floor; eligible ordinary enemies can become champions with higher HP and defense, stronger EXP/Gilda rewards, and increased incoming damage while near the player. Champion drops use the legacy themed pools; champion weapon boosts and weighted rarity rolls apply to the exact acquired weapon instance; and size is configurable through a cleanup-aware native scale hook. When Dungeon+ is enabled, floor tier adds configurable XP and champion-chance increments (25% and 4 percentage points per tier by default); Ascension still works alone. Champion EXP and Gilda multipliers are separate settings. Keen Edge matches the legacy +4% damage per rank. Deadly Aim adds +3 percentage points of crit chance per rank; Ruthless adds +20% crit damage per rank and requires Deadly Aim rank 2; Executioner requires Keen Edge rank 3. Native hits use the legacy base 8% crit chance and +0.05 percentage points per equipped weapon-speed point, plus +75% crit damage with Ruthless ranks. It also applies uniform ±10% damage variance, +30% Executioner damage below 30% enemy HP, and level-based incoming mitigation capped at 40%.

Treasure Hunter follows the legacy reward math: ordinary enemies grant the configured extra Gilda share (50% by default), with each rank increasing that bonus by 10%. Champions use their configured native Gilda multiplier; Treasure Hunter adds its rank bonus to that champion reward. The payout is capped to the native currency API's per-call limit.

Weapon Mastery now belongs to Ascension. Kills count against the weapon type's stable ID regardless of which party character used it; thresholds are 25, 75, 150, 300, and 600, with a configurable 2% damage bonus per rank by default. The former standalone MoonMod mastery package is a one-time storage import bridge. If it contains saved kills, enable it with Ascension once; its Actions tab also has an import button. It does not own ongoing mastery gameplay. Ascension also includes Sturdy's original 50% weapon-durability refund and 30% thirst refund defaults in its Settings; the Survivalist skill adds 6 percentage points per rank to the thirst refund. Full native kill-attribution and weapon-class confirmation still requires an in-game pass.

## Dungeon+

Dungeon+ keeps its per-floor tiers, procedural layout requests, enemy resilience, Gilda bonus, and queued clear rewards. It adds:

- Per-floor tier selection from the dungeon entrance list with `[` / `]`; Chronicle draws the tier badge beside each floor. New floors default to Normal (tier 0). Defaults match legacy tier effects: +35% enemy HP, +2 defense, +40% enemy Gilda, +25% Ascension XP, and +4 percentage points of champion chance per tier; Dungeon+ Settings can adjust each modifier. With Ascension enabled, its enemy-scaling path composes the tier bonuses with dungeon/floor/champion effects; without Ascension, Dungeon+ applies the native HP/defense/Gilda modifiers itself.
- Room-linked population targets: defaults request 1.5–3 monsters and 0.75–1.5 regular chests per realized room. For 20 rooms, that means 30–60 monsters and 15–30 regular chests before native minimums and storage ceilings are applied. The density ratio is derived deterministically from the floor seed; native targets always win when larger (15 regular-floor monsters, 8 back-floor monsters, and 4–7 regular chests before modifiers). Dungeon+ settings let the player adjust both ranges, and **Room Population Status** in Actions reads active Ascension additive bonuses, then shows realized rooms, effective native minimums, requested target ranges, and native caps (255 monsters, 48 regular-chest targets; 64 physical box slots with 16 reserved for mimics/special boxes). These are requested targets, and placement can fall short if a layout runs out of valid positions. The PC event array has 384 entries; retail capacities remain unchanged.
- Eligible ordinary enemies now have the Enemy Variety get-back-up roll: default 25%, one attempt per enemy life, 30% HP and a 70-step stop; key holders, bosses, and enemies with 3000+ max HP are excluded.

- Dungeon Feats: kill, streak, floor-clear, and species trophies in Journal; legacy floor-clear Gilda payouts, streak bonuses, trophy rewards, and bestiary rewards at 10/50/150 defeats per species use the configurable 0–300% reward scale (default 100%). The live streak and streak payouts are surfaced through the manager notice and status action.
- Bestiary records keyed by native enemy model ID. **Browse Bestiary** in Actions cycles through the original native enemy catalog, including unseen enemies, and any encountered mod enemies; entries show kill counts and the next 10/50/150-kill reward milestone.
- Floor Bounty: the first living ordinary enemy in native slot order becomes the target as soon as its model mapping is available, with first-defeat fallback; progress resets on each floor visit, including a revisit to the same seed. The default target is six kills and the payout follows the legacy floor-rounded formula. Reward scale and kill count are Settings.
- Six floor mutators: Glass Cannon, Iron Hide, Bounty, Fountain, Scorched, and Lucky Day (15% chance to double a hit). Chance defaults to 35%, plus 3 percentage points per dungeon, capped at 100%; the roll occurs on each floor entry, as in the legacy floor-change hook. Iron Hide and Bounty adjust each revealed enemy's native Gilda reward once per life.
- Enemy variety: each living enemy gets a stable per-floor speed roll, default plus or minus 25%, and eligible ordinary enemies can get back up once with a configurable chance (25% default), 30% HP, and 70-step stop. Key holders and enemies at 3000+ max HP are excluded. Speed updates only write native movement intent and skip knockback.
- 3D model replacements: loaded packages may include `models/<texture>.obj` or `models/<texture>.glb`; `<texture>__<vertex-count>v` limits a replacement to matching source meshes. An optional sibling JSON sidecar accepts `scale`, `rotate_deg`, `offset`, and `flip_v`. Later packages in the resolved MoonFactory load order override earlier package assets, with exact-vertex files preferred to generic texture files. Replacement meshes keep the original texture/material strips and follow native animation through the Chronicle renderer's skinning hooks. Files above 64 MiB are skipped. Both authoring conversion and runtime GLB loading flatten scene instances, apply node transforms, expand sparse accessors, and triangulate triangle, strip, and fan primitives. The runtime replacement path, package PNG texture overrides, and adapted authoring GUI are source-integrated; comparison with the user's assets still needs review. See [MODEL_REPLACEMENTS.md](MODEL_REPLACEMENTS.md). The aerial dungeon map is a separate native renderer option with fit-to-screen behavior; it does not use the 3D mesh replacement loader.
- Expanded Data parity: all 64 native base weapon definition rows (including stat caps, sockets, effects, and build-up masks), all 119 price rows, Gaffer's and Fairy King's base shop edits, and five-day stock pools across seven shops. Chronicle exposes an adventure-day read and owner-restored native weapon/shop overrides. The native fixed-size table accepts all 20 goods and preserves repeated IDs used for stock weighting; shorter lists retain their `-1` terminator. Selection is stable by shop and day, rather than reusing the legacy script's global sequential random stream. Failed shop reads/writes retry after a short backoff. Existing saved weapon instances retain their previous values; shop refresh timing still needs in-game confirmation. The package includes the DarkCloud-Expanded BSD-2-Clause notice.

## Legacy feature notes and remaining checks

- The Windows Expanded Abilities package explicitly omits new visuals, clone actors, and weapon-generation rolls. Its eight shipped effects are the parity scope: Mobius Ring's charge uses a timed native damage formula; other effects include Cross Hinder versus undead, Brave Ark cleansing, weapon status procs, Cactus water return, and Aga's Sword damage reduction.
- Harder AI now includes the legacy five enemy STB overrides as Dungeon+ package resources. The native loader falls back to retail data if an override is larger than its matching game file; runtime compatibility still needs an in-game check.
- Expanded Data now includes its 64 native weapon-definition changes, 119 price rows, Gaffer's/Fairy King's base stock edits, and deterministic five-day stock rotations. Chronicle exposes its saved adventure day and restores weapon, price, and shop-list edits when Dungeon+ unloads. Duplicate native shop entries remain supported for stock weighting, and a daily item may use the twentieth slot. The native shop's refresh timing still needs in-game confirmation.
- Enemy speed writes can be replaced by the game's AI on a later movement step; Dungeon+ reapplies the stable roll while active.
- Ascension now ports the original per-dungeon champion loot pools, rare/common themed drops, back-floor keys, weapon pools, champion weapon boosts, and weighted Fine/Superior/Exquisite/Legendary stat rolls. Chronicle's native pickup event reports the exact new weapon instance so these rolls do not mutate another copy. Champion size is configurable and uses an owner-scoped native scale hook that restores the original size on actor reuse or mod unload. Dungeon+ tier XP/champion chance multipliers are now applied through Ascension's optional callable-mod dependency. Enemy scaling writes are generation-checked across the expanded 256 actor slots and apply as revealed enemies enter the active roster. Weapon-speed crit chance is implemented using the active weapon's native speed and refreshed on supported equip/party events and periodically for native-menu swaps. The aerial dungeon map and fit-to-screen options are source-integrated in Chronicle's native renderer; user-run confirmation remains outstanding. The model-replacer GUI and package PNG texture overrides are source-integrated; comparison with the user's actual assets and audit of GLB accessor limits remain open.
- Toughness's +4% maximum-HP effect and Ascension's XP, Paragon, skill ranks, and weapon mastery use Chronicle's `game.save.slot_id()` result, including its persistent `slot_generation`, as a composite key. Older number-keyed records migrate to that key. Chronicle changes the generation when a numbered save is deleted and its number is reused; in-game verification of that lifecycle remains outstanding.
- Regular chest targets now cap at 48 on the PC port, with 64 physical box slots (16 reserved for mimics/special chests) and 384 shared event records. Room Population Status reports clipping at the 48-chest target. This expansion is source-integrated but needs an in-game pass for event-heavy floors.
- The in-scope Windows gameplay packages are consolidated into Ascension, Dungeon+, and the small Autosave, Controls, Expanded Town, and Hub packages. Current source integrations and the remaining runtime-only checks are itemized in [LEGACY_MOD_PARITY_PLAN.md](LEGACY_MOD_PARITY_PLAN.md); no required legacy behavior is currently identified as blocked on a missing native hook.

## Persistence and release status

Progression and skill ranks are scoped to Chronicle's native save slot; floor choices, bestiary records, bounty progress, and mutator selections use package save data or the framework quest journal. Native game saves and MoonMod storage are not one transaction, so save after leveling and avoid interrupting the game during a save.

No game launch, gameplay test, or headless test was run. This is a source-level integration, not a verified release claim.
