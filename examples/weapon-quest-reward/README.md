# Weapon Quest Reward

This cross-game example defines a quest with one native weapon reward. The stable weapon ID is game-specific: Chronicle uses `chronicle:weapon:258`, while Chronicle Two uses `chronicle-two:weapon:80`.

Enable the mod, then open its **Actions** tab in the MoonFactory manager. Start the trial and complete it. The completion event reports whether the native inventory accepted the reward.

The example grants one weapon from the game's existing weapon table. It does not define a new weapon or change any model assets.
